# Swapnil Gaurkar | Portfolio Website

Self portfolio website built for the CA3 Mini Project (JavaScript Lab).

Live site: https://swapnilgaurkar.github.io/portfolio/

## Sections
About, Education timeline, Technical skills, Projects, Achievements, Certificates, Contact

## Built with
HTML, CSS, JavaScript (no frameworks)

## Features
- Scroll-driven education timeline
- Skills filter with animated bars
- Expandable project cards
- Dark / light theme toggle
- Downloadable resume

## Run locally
Open index.html in any browser.
